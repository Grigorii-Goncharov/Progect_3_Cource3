# Курсовой проект 3 Course-project3-Vacancies_DB (Поиск вакансий)

## ОПИСАНИЕ: 

Course-project3-Vacancies_DB  — это консольное приложение для поиска и анализа вакансий с помощью HeadHunter API,
с возможностью фильтрации, сортировки и сохранения результатов в JSON-файл.

##  Как использовать:
Для установки и запуска проекта необходимо выполнить следующие шаги:

Клонируйте репозиторий:

git clone https://github.com/Grigorii-Goncharov/Progect_3_Cource3.git

##  Основные возможности
* Поиск вакансий через HeadHunter API
* Поиск вакансий по ключевому слову
* Получение списка работодателей по текстовому запросу.
* Фильтрация и сортировка вакансий.
* Фильтрация вакансий по ключевым словам в названии или описании.
* Работа с базой данных.
* Сохранение вакансий и информации о работодателях в базу данных PostgreSQL.
* Установка и инициализация базы данных при первом запуске (если не существует).
* Получение и удаление вакансий из базы данных.
* Сохранение и экспорт данных.
* Пользовательский интерфейс.

python main.py
